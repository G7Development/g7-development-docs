# G7 Development Documentation Website

## Publish updates

1. Extract this ZIP.
2. Copy the contents into your local `g7-development-docs` repository, replacing the existing files.
3. In GitHub Desktop, review Changes, commit, and click Push origin.
4. Cloudflare Pages should deploy automatically from the `main` branch.

## Website structure

- `index.html` — site shell, navigation layout, and Discord support links.
- `styles.css` — G7 styling.
- `app.js` — navigation, search, and Markdown rendering.
- `docs.json` — all documentation content.
- `assets/g7-mark.svg` — G7 mark.

G7 Lean System is intentionally a single article under **G7 Scripts**, using the supplied `leansystem.md` installation guide. The older split Lean System articles have been removed. Discord support links point to https://discord.gg/P6XQ4N6M95.

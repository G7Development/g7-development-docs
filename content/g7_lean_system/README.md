# G7 Lean System

Welcome to the official **G7 Lean System** documentation by **G7 Development**.

G7 Lean System is a FiveM roleplay drink-preparation resource with a branded NUI mixing interface, configurable syrup and soda profiles, metadata-backed drink items, sip tracking, optional visual/movement effects, and inventory/framework adapters.

> **Resource name:** `g7_leansystem`  
> **Version documented:** `1.0.0`  
> **UI accent:** `#5b376a`

## Before you begin

The resource package is the source of truth for supported behavior. This documentation describes the `g7_leansystem` v1.0.0 files. Custom inventory builds, third-party exports, and streamed assets can differ between servers; validate those parts on a test server before production use.

## Support

For help, contact G7 Development through the support channel listed on the product page or your purchase documentation. When requesting help, include your framework, inventory resource and version, relevant server console output, and the steps needed to reproduce the issue. Do not send server keys, credentials, or player personal data.
